# _StoreKit_SwiftUI

Perry's `_StoreKit_SwiftUI.framework`: StoreKit's SwiftUI API, of which
`EnvironmentValues.requestReview` is here, asking nothing as there is no App
Store to review the app in. `Scripts/build-storekit-swiftui.sh` builds it on
a Mac, after `Scripts/build-swiftui.sh`, against Perry's SwiftUI.
